# Sioux Falls, SD — Landmark Run

Reviewed full native desktop and handheld at 30, 45, 65, 105, 175 and 265 m. Falls Park passes in both at 65 m: stock dipped headlights reveal the ruined mill masonry and its row of openings while the broken tower clears the horizon. Old Courthouse clock face, Pettigrew house facade, and Pavilion architectural details are too dark in native views and remain pending.
