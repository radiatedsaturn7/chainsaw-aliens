# Wilmington, DE — Landmark Run

The Grand Opera House’s distinctive upper facade and tall voids read at 175 m, and the Delaware History Museum’s window grid and broken corner read at 45 m, in both standard native modes. The Chase Center and Rodney Square remain pending: their low profile loses definition against existing hills and foreground in handheld. All four are registered and collision-clear. Original conditions and scenery were preserved.
