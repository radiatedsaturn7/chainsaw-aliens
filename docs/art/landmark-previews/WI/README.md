# Milwaukee, WI — Landmark Run

The Pabst’s damaged arched facade reads in both native views at 45 m. The Art Museum’s broken wings and City Hall’s high bell tower read in each mode at 135 m. The Harley-Davidson Museum is registered and road-clear but its distant silhouette blends into foreground/background in handheld mode; it remains pending. Existing road, props and author lighting were not moved or changed.
