# Denver landmark approaches (2994)

Native day lighting and original world, with placeholder car. Standard desktop
and handheld playtest renders show Coors Field at 65/105 m, Union Station at
240 m, and the Denver Art Museum's Martin Building at 65 m. The State Capitol
plays clearly at 135 m on desktop, but pending handheld QA is tracked in the
ledger because the crest is too near the frame edge or pause control.

Approaches are relative to the final safe projection, not survey mileage.
Road geometry, lighting, and existing scenery were preserved.
