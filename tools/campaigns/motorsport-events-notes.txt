MOTORSPORT EVENTS

World map: Race Index (all installed races), Championships, Rally.
Definitions and pure rules: src/menus/MotorsportEvents.js
Standard menu controller: src/menus/MotorsportMenu.js
Index metadata is generated by tools/campaigns/route_previews.mjs.
No imported track geometry or vehicle physics is changed by event overlays.

Championships: American Apex, British Club, Continental Cup, World Masters.
Three authored closed circuits each, three laps, six drivers, heat 1–3.
Suzuka East is used because the imported GP/West layouts currently fail the
closed-circuit eligibility check. Ineligible or missing rounds hide a cup.
AI uses independent snapshots of the entered car build; no rubber-banding.
Points: 25,18,15,12,10,8. Ties: wins, then finishing-place countback.
At the player's finish, already-finished AI retain crossing order; cars still
running are classified by progress. This is flag-time classification, not
waiting for every trailing car to finish.

Rallies: 21 imported collections, two formats each (4 / 12 stages).
These are authored game itineraries, NOT complete historical WRC itineraries.
Available roads cycle as labelled repeat passes. Rivals use deterministic,
independent benchmark times derived from each road's estimated duration;
they are not live on-stage AI and require playtesting for competitive balance.
Short: 60 service points after stage 2.
Full: 30 after stage 3, 60 after stage 6, 30 after stage 9.
Engine/drivetrain repair only at full service. Other jobs include tires,
suspension, brakes, cooling, fluids/electrical. Points expire at the next start.
Damage and fluids carry between stages. Garage repairs do not overwrite the
event condition snapshot. Entered car and installed/tuned setup are locked.

Event state is JSON inside profile progress.motorsportEvent, isolated per save.
Results save before advancing; callbacks check event ID and round index.
Resume continues the saved event. Restart retries the current round and retains
current damage. Retire requires confirmation and discards event standings.
Event rounds deliberately do not award ordinary campaign completion/unlocks.

Validation: unit event rules, menu navigation, profile saves, race launch and
finish/restart regression tests. Browser flow test is in menu-editor.spec.js;
GitHub Docker Playwright is authoritative on Android/Termux.
