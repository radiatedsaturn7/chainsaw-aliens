# Moonpetal GT 2000

Original angular three-door liftback inspired by the US 2000 GT-S six-speed manual with standard 205/55R15 tires. No TRD or optional 16-inch package. OEM engine, mass and metric dimensions retained; Australian physical gearbox ratios corroborated by rounded US secondary values remain a disclosed cross-market inference. Tach redline is secondary and ECU fuel cut remains unknown, with an explicit simulation estimate.

Original native exterior and LHD dashboard, individually fitted shared wheel and upper-opening gauges. Actual eight-view and desktop/mobile cockpit browser acceptance remains a release gate. No maps changed.
