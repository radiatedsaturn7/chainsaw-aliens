# Copperwing 2004
Original logo-free 2994 fastback coupe with source-backed 2004 US Chrysler Crossfire 3.2 V6 six-speed manual reference. Not an SRT-6 or roadster. See research.md, import.json provenance and prompts.json for sources, conflicts and explicit estimates.

The final owner's manual dimensions and mass take precedence over preliminary press specifications: 1389 kg, 4058 × 1766 × 1307 mm, 2400 mm wheelbase and 1493/1502 mm tracks. Engine 160 kW/310 Nm, RWD, six-speed manual and final drive 3.270. The 2.70 summary is overall top-gear reduction, not another final drive. Front 225/40ZR18 and rear 255/35ZR19 nominal radii are independently represented (0.3186/0.33055 m). Runtime suspension, CG height, off-peak torque, shift time and economy remain explicitly estimated; acceleration/top-speed source references are not a certified simulation result.

Body and cockpit are original native imagegen PNGs. A targeted native edit corrected the rear-left orientation; all eight alpha openings were remeasured. Fixed rear camera, appropriate non-turbo smoke, shared steering wheel and per-car wheel-opening gauges use the existing editor serializers. Exterior gauges reused; interior placement individually authored for this dashboard. No maps changed.

Local source regression, editor roundtrip, production-editor launch and all-angle alpha/wheel coverage tests are included. Actual desktop/mobile cockpit screenshots and in-game eight-angle visual acceptance must pass on the published exact head before release; this local preparation is not that acceptance.
