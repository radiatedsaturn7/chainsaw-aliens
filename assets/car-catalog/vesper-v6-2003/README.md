# Vesper V6 2003

Original logo-free 2994 mid-engine hatch, inspired by the German 2003 Phase II V6 specification. Native eight-angle transparent body and LHD cockpit; shared runtime steering wheel and tires. Physical front/rear tire geometry is independently staggered.

Sources and game estimates are separated in `research.json`. OEM service supplement tooth counts resolve rounded/internally conflicting launch data; 187 kW is converted to mechanical horsepower. Curb mass subtracts the explicitly included 75 kg driver from the German 1475 kg figure. No claim of licensed reproduction or simulator-level OEM certification.

Import through `scripts/car-catalog-import.mjs`. Final exact-head browser inspection must cover all eight exterior angles and mobile/desktop cockpit after CI. No world, map or race files changed.
