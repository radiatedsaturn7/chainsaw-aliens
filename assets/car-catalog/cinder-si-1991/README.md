# Cinder Si 1991: runtime draft

Original logo-free year-2994 salvage wedge hatch, inspired by US1991 CRX Si SOHC non-VTEC5MT. This is not JDM SiR and does not complete that candidate.

The two unchanged native PNGs feed `import.json` through the real Car Editor normalization/serialization path. Individually measured alpha openings, mapped eight-angle views, fixed rear camera, shared steering wheel, dashboard-space gauges and existing surface smoke/spray are configured. No maps or worlds change.
