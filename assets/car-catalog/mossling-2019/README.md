# Mossling 2019

Original logo-free 2994 compact utility SUV, based on the UK 2019 Jimny SZ5 five-speed/full-options reference. This playable configuration is specifically **dry-road 2H rear drive** with 1.000 high transfer  ratio. Selectable 4H/4L and brake-based cross-axle traction are not implemented; this is not a complete Allgrip controller simulation.

Suzuki GB launch brochure anchors 75 kW at 6000 rpm, 130 Nm at 4000 rpm, 1135 kg full-options kerb mass, 1462 cc, five-speed 4.425/2.304/1.674/1.190/1.000, reverse 5.151, final 4.090, 40 L, 195/80R15 and 210 mm clearance. Do not substitute Croatian minimum 1090 kg, gross 1435 kg or automatic transmission ratios. OEM 75 kW is retained despite inconsistent 101 PS label. Source 145 km/h is a reference, not a verified runtime result.

Other curve points, 6500 redline/6700 limiter, idle, steering, distribution, CG, drag, pressure, suspension and 13.5 s 0–60 are explicitly provisional. Rigid axle motion is approximated by existing runtime wheel contacts. Front discs/rear drums are source facts, not fully modeled brake hardware.

Original transparent eight-angle body, new RHD utility cockpit, fitted gauges, shared wheel/tires, fixed-rear camera and surface smoke. Native editor/launch tests and actual screenshots gate release. No map/world changes.
