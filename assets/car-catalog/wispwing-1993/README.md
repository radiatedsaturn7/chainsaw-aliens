# Wispwing 660 1993

Original tiny mid-engine coupe with closed gullwing doors, inspired by JDM January 1993 Suzuki Cara base 5MT RHD. Official Suzuki technical table verifies physical ratios, dimensions, vehicle mass and engine figures. PS and kgf-m are converted, not confused with mechanical hp or Nm. Redline, cutoff, boost and differential remain explicit simulation estimates. Cara/AZ-1 family is one distinct design, not separate badge duplicates.

Native original artwork with individually fitted right-side wheel-opening instruments. Actual eight-view and desktop/mobile cockpit acceptance remains a release gate. No maps changed.
