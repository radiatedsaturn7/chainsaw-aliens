# Rue 2011

Playable fictional 2994 restoration of the 2011 US Nissan LEAF SV, an early front-drive electric hatchback with 80kW motor,207lb-ft torque and24kWh nominal battery. The selected SV has the standard16inch wheels and lacks the SL's solar spoiler and fog lights. This is not a later battery upgrade or the 2012 cold-weather specification.

[Nissan's original2010-10-28 press kit](https://usa.nissannews.com/en-US/releases/2011-nissan-leaf-press-kit-3) supplies power, torque, drivetrain, nominal capacity, tires, body dimensions, aerodynamics and interior layout. The public [two-page OEM specification transcription](https://www.scribd.com/document/668786894/nissan-leaf-2011-specs) distinguishes3366lb SV curb weight from3375lb SL and supplies tracks. Both public webpages were read and their HTML retained. The latter was available as a full text transcription, not an authenticated PDF download; that access limitation is recorded in provenance. A 2012 brochure and unsuccessful2011manual retrieval were retained outside the repository as research, but supply no runtime facts.

The estimated21kWh usable capacity is separate from24kWh nominal. The7.937reduction, motorlimit, regeneration limits, efficiencies, performance targets, mass split, tirepressure and suspension parameters are explicit simulation estimates. Original source units and all assumptions appear in `import.json`. The kW gauge reads battery input including modeled losses, so it can exceed the80kW mechanical motor rating. No laboratory range is presented as measured game range. The existing electric drivetrain consumes and regenerates modeled energy.

Original badge-free blue2994 exterior art has eight distinct reviewed views, empty authored wheel openings fitted to the shared animated tire rig, and a preserved initial atlas plus spacing revision. The fitted LHD dashboard uses the early twin-level meter layout, with live speed,battery-input kW,gear and battery widgets and a shared animated wheel. No manufacturer image pixels enter game layers.

Validation includes37 focused unit checks for source boundaries, single-reduction drivetrain, energy consumption/regeneration, editor roundtrip, roster identity, wheel fit and existing electric integration. Four browser checks cover moving desktop keyboard/handheld touch gameplay, eight editor views and cockpit compositing, and the real static picker initial entry/art followed by this later page, loaded exterior and cockpit driving. Manifest check covers1910documents and16assets. Evidence validates functionality and movement, not historical acceleration calibration.
