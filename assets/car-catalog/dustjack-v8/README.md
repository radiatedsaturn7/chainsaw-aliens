# Dustjack V8 research import

Original fictional desert coupe, using an explicitly approximate Rally Fighter LS3 high-ride representative build. No model-year or universal factory trim claim.

`import.json` records sourced numeric anchors and simulation estimates separately. 3900 lb is the midpoint of a published range; width has conflicting inch/metric source values. Four-speed 4L85E ratios are component-manufacturer facts; installation and 4.11 axle ratio come from one documented build. Do not combine this with TH400 or custom supercharged configurations.

Current importer builds through Car Editor serialization. Art wheel-well anchors were manually measured, shared steering wheel retained, Offroad tire graphics reused. Browser exterior alignment, cockpit instrument placement and driving behavior still require review. Build artifacts live outside the shared runtime manifest until integration.
