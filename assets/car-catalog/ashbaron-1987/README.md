# Ashbaron 1987

Original, logo-free 2994-style salvage coupe inspired by the production 1987 Buick GNX. The body and cockpit are newly generated artwork, not copied manufacturer imagery. Shared steering-wheel artwork is reused.

Production engine ratings are 276 hp at 4,400 rpm and 360 lb-ft at 3,000 rpm. Period prototype ratings of 300 hp / 380 lb-ft are deliberately excluded. Secondary-source mass and dimensions are documented, not presented as factory-verified GNX figures. The factory Regal transmission specification is explicitly a related-model source; custom GNX converter/shift behavior is modeled approximately.

Four-speed automatic, RWD, staggered 245/50R16 front and 255/50R16 rear tires, fixed rear camera, and surface-responsive tire smoke/spray. Dashboard gauges and the shared wheel are individually positioned against the original cockpit image. Runtime physics, artwork alignment, and cockpit layouts require exact-head browser validation before release.

See import.json, research.json, and research-supplement.json for sources and estimates, and prompts.json for artwork prompts. No maps, worlds, existing cars, or physics-engine code are changed.
