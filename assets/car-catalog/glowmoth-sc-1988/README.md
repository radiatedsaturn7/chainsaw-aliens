# Glowmoth SC 1988

A source-qualified US 1988 supercharged manual powertrain variant of the Glimmer wedge family, not a wholly new body family. OEM brochure engine, curb mass, dimensions and 42/58 distribution were visually verified. E51 physical gearing remains corroborated secondary evidence, not an authenticated OEM numeric table. Engine limits, boost response and clutch behavior are explicit simulation estimates.

Native original orange/charcoal artwork has closed T-bar panels and individually measured transparent wheel openings. LHD instruments use the shared wheel-opening layout. Actual eight-angle and desktop/mobile cockpit acceptance remains required. No maps changed.
