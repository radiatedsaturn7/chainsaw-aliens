# Rotarypetal 2011

Original logo-free 2994-style artwork and native car-editor document. Source boundaries and simulation estimates are recorded in research.json and import.json.

Exterior uses eight distinct views with transparent wheel wells, shared runtime tires, fixed rear camera and individually placed cockpit instruments under the shared steering-wheel arch. Final acceptance requires exact-commit production launch, all eight rendered directions and 390/1280 cockpit review.

RX-8 rotary output uses a supported generic torque curve, not rotor or rotary combustion simulation. OEM torque-sensing LSD is approximated by supported axle locking parameters.
