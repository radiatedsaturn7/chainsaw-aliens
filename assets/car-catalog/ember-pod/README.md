# Ember Pod Prototype

**Prototype-target simulation, not a verified production car.** Original fictional TAMO Racemo-inspired petrol coupe; no production model year asserted.

800 kg is a reported development target, not measured curb mass. Manufacturer 190 PS at 6500 rpm converts to 187.4 mechanical hp; torque is 210 Nm at 2500 rpm. Dimensions, wheelbase and staggered tire sizes are sourced. Individual gear ratios, final drive and reverse are explicitly modeled, NOT sourced Racemo or borrowed Nexon facts. Sixth is designed for a selected 220 km/h at 6500 rpm using nominal rear radius; that speed is our design target, not OEM performance.

Current single-size runtime uses rear 235/45 R18 geometry (.33435 m nominal radius); source front 205/50 R17 (.3184 m) remains recorded, but true staggered sizing is not implemented. Paddle AMT behavior is approximated using manual shifts with zero clutch delay. Full curve, chassis dynamics, tracks, CG, steering and shift timing remain estimates.

Original body/dashboard inspected; eight angles calibrated from measured openings (front/rear axes inferred behind shell). Existing shared steering wheel reused. Three unit tests cover model disclosures, wheel openings and editor roundtrip. Browser/driving QA remains pending.

Source configuration recovered from preserved built-car provenance and original measured wheel anchors after workspace recovery. No runtime manifests changed.
