# Marigold 1991
Original logo-free 2994 retro coupe with worn ochre paint and cream roof, inspired by the 1991 Japanese Figaro 3AT. Native eight-angle exterior and RHD dashboard, shared runtime tires/steering wheel, fixed rear camera, surface smoke and individually calibrated instruments.

Nissan heritage data supplies 810 kg curb mass, 55.9 kW at 6000 rpm, 105.9 Nm at 4400 rpm, 987 cc displacement, dimensions and 165/70R12 tires. Both scanned pages of the archived Nissan February 2015 information letter were visually checked: 40 L fuel tank, three automatic ratios, reverse and final drive, and brake geometry. Gross weight and gross axle loads are not substituted for curb values. Factory no-ABS is recorded; runtime assists remain player-controlled. Unverified handling and performance values are explicitly estimates.

Release requires exact-head CI, actual eight-angle and 390/1280 cockpit review, native editor roundtrip and production launch. No maps, worlds or races changed.
