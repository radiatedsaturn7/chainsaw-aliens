# Tansy Cargo 2010

Original badge-free 2994 compact cargo van based on the US 2010 Ford Transit Connect XL Van, 2.0 petrol FWD four-speed automatic, two seats and solid cargo panels. Not the passenger Wagon, European diesel or electric conversion. No matching source model/alias exists in the saved 85-entry roster.

Primary reference: [original Ford 2010 brochure, publication 10TCONWEBPDF](https://manuals.plus/m/a0ce73c8f80e07f38df4ab7c871980112907aa6ff770455aa0950076cfd14445), archived manufacturer document. Standard Van configuration and dimensions were read directly. The brochure gives a generic Cargo Van curb mass; it is used as the unladen baseline, not represented as a weighing of an option-specific XL. Mirror-inclusive width is not used as collision-body width.

`research.json` separates verified specifications from game estimates. Individual transmission ratios, final drive, engine-curve RPM anchors, body width, CG, weight distribution, suspension, tire pressures and display performance are explicitly provisional. No factory manual, cargo-loading system or faithful OEM stability/leaf-spring simulation is claimed.

Original source PNGs and supported image-generation corrections are recorded in `generation.json`. The initial body required opposing-angle correction and removal of white roof-edge artifacts; the final blue-roof artwork is retained unchanged and imported through the native editor. All eight views use shared wheel graphics fitted to measured openings. The blank LHD binnacle receives live speed/RPM/gear/fuel instruments through the shared wheel opening. Fixed rear camera and existing surface effects remain intact.

Validation covers source/native serialization and hashes, tire geometry, source-count/parity, the prior eight-car batch, eight actual exterior preview views, moving desktop/handheld cockpit previews, readable production cockpit composition, and asset manifest checks. This is production driving-preview evidence, not full campaign acceptance or calibrated acceleration testing.
