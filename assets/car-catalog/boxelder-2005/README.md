# Boxelder 2005

Original 2994 box wagon using US2005 standard xB LHD5MT brochure anchors. Individual gears are explicitly provisional secondary-corroborated, not OEM-verified. Original driver binnacle deliberately differs from OEM center gauges; blank center display retained. See research/import provenance for estimates. Actual desktop/mobile cockpit, eight-view and launch browser acceptance remain release gates. No maps changed.
