# Foxglove Z 2003

Original logo-free petrol-blue/copper V6 fastback, inspired by the US 2003 base coupe with six-speed manual transmission. OEM service-manual gears were visually verified; the mirrored trim/mass table retains its provenance limitation. Standard staggered tires and open differential are preserved.

Native transparent body and dashboard were generated using the built-in image tool; exact prompts and references are recorded in prompts.json. Actual eight-angle and desktop/mobile cockpit browser acceptance remain pending. No maps changed.
