# Data Model: Dynamic Track State

## TrackStateSession

The authoritative evolving surface owned by one race playtest session.

Fields:

- `version`: snapshot/schema version.
- `seed`: deterministic unsigned session seed.
- `cellSizeM`: exactly 1 for this feature.
- `fixedStepMs`: authoritative environment interval, 100 ms.
- `stepIndex`: last completed fixed step.
- `accumulatorMs`: unsimulated render time; excluded from canonical checksum.
- `cells`: sparse map keyed by `x,z`.
- `orderedCellKeys`, `cellCursor`, `maxCellsPerStep`: canonical rotating work
  budget that prevents whole-track periodic scans.
- `events`: pending normalized events ordered by step and stable identity.
- `eventHistory`: deterministic applied events retained for replay.
- `carryByTire`: dirt/mud/debris carry keyed by `vehicleId:wheelId`.
- `weatherTimeline`: compact step-indexed environmental forcing history.
- `totals`: precipitation, drainage, evaporation, and material-conservation
  diagnostics.

Validation:

- Integers identify cells and steps.
- Persistent numbers are finite, non-negative where they represent mass/depth,
  and quantized to six decimal places.
- Events cannot target a completed step unless processed through explicit
  deterministic catch-up.
- Map identity never depends on object insertion order.

## TrackStateCell

One square meter centered at integer-derived world coordinates.

Identity and geometry:

- `x`, `z`: integer cell coordinates.
- `key`: canonical `"x,z"` string.
- `baseSurfaceId`, `materialId`, `region`.
- `elevationM`, `normal`.
- `initializedStep`, `lastUpdatedStep`.

Persistent state:

- `surfaceTemperatureC`.
- `moistureDepthMm`.
- `standingWaterDepthMm`.
- `rubber`.
- `looseMarbles`.
- `dust`.
- `dirt`.
- `mud`.
- `oil`.
- `snowDepthMm`.
- `iceDepthMm`.
- `roughness`.
- `drainageRateMmPerS`.
- `sunExposure`.
- `windExposure`.
- `debris`.
- `compaction`.
- baseline condition values used to ensure the existing authored material is
  the neutral physics state while subsequent accumulation/removal changes it.

Derived sample values are calculated, not persisted:

- effective surface ID;
- grip multiplier and effective grip;
- rolling-resistance multiplier;
- hydroplaning, contamination, and loose-material risk;
- visual tint/wetness/rubber/debris values.

## BaseSurfaceProfile

Data-driven defaults selected by normalized surface/material identity.

Fields:

- base grip, rolling resistance, and thermal response;
- permeability and saturation depth;
- drainage range;
- default moisture/snow/ice/loose material;
- roughness;
- rubber acceptance;
- sun and wind exposure defaults.

Profiles cover existing asphalt, wet asphalt, dirt, gravel, wet gravel, mud,
snow, slush, grass/terrain, and a generic fallback.

## TrackStateEvent

Common fields:

- `type`: `tire-contact`, `crash-debris`, `oil-spill`, or an extensible
  data-driven type.
- `stepIndex`.
- `sequence`.
- `vehicleId`.
- `wheelId` when applicable.
- `x`, `z` world location.
- `payload` with only canonical JSON-compatible values.

Ordering:

1. `stepIndex`;
2. event type order;
3. `vehicleId`;
4. `wheelId`;
5. `sequence`;
6. target cell key generated by swept traversal.

## TireContactEvent

Additional fields:

- previous and current physical contact locations;
- grounded/contact scale;
- normal load;
- speed and traveled distance;
- forward/lateral direction;
- slip ratio/angle and slip energy;
- brake lock and driven wheel spin;
- tire compound;
- tire temperature.

State transition:

1. Ignore if not grounded.
2. Enumerate all crossed one-meter cells.
3. Deposit rubber and heat based on load, slip energy, and distance.
4. Displace water and loose material to deterministic directional neighbors.
5. Sweep marbles.
6. Pick up local dirt/mud into tire carry.
7. Deposit a diminishing carried load on later cells.
8. Quantize/clamp cell and carry state.

## WeatherForcing

Fields:

- `stepIndex`;
- weather type and precipitation phase;
- precipitation rate;
- ambient temperature;
- sun intensity/direction;
- wind intensity/direction;
- humidity/evaporation scale.

Weather acts on a deterministic rotating budget of persistent cells using
exposure, material, temperature, and drainage. Exact tire/AI samples lazily
catch a cell up from the same timeline before returning it.

## LocalSurfaceSample

Returned for exact world coordinates:

- cell identity and immutable base geometry;
- all persistent cell values;
- `effectiveGripMultiplier`, `effectiveGrip`;
- `rollingResistanceMultiplier`;
- `hydroplaningRisk`, `looseMaterialRisk`, `contaminationRisk`;
- `effectiveSurfaceId`;
- visual state and deterministic step index.

## CanonicalSnapshot

Fields:

- schema `version`;
- session initialization metadata;
- `stepIndex`;
- rotating cell cursor and per-step cell budget;
- sorted `cells`;
- sorted pending `events`;
- sorted applied event history;
- sorted `carryByTire`;
- sorted `weatherTimeline`;
- conservation totals;
- checksum calculated over the snapshot payload without the checksum field.

Restore rules:

- Reject incompatible versions or invalid numeric values.
- Reconstruct maps from sorted arrays.
- Reset render accumulator to zero.
- Preserve step/event ordering exactly.

## TrackStateSyncPacket

Types:

- `snapshot`: complete canonical starting/restoration state;
- `events`: sorted step-indexed event batch;
- `checksum`: step index plus canonical checksum;
- `resync-request`: expected step/checksum information.

Packets are transport-neutral plain data. Applying a duplicate event batch is
idempotent by stable event identity.
